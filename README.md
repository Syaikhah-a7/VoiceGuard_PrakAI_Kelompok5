# VoiceGuard_PraktikumAI_Kelompok5
## Model
Model `.keras` tersimpan di Google Drive:
[Download model_ai_voice.keras](https://drive.google.com/file/d/GDRIVE_ID_DARI_DIVISI2/view)

## Cara menjalankan lokal
1. Clone repo ini
2. Download model dari link di atas, taruh di folder `models/`
3. `pip install -r requirements.txt`
4. `python app.py`
5. Buka `http://localhost:5000`
